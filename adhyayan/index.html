Adhyayan

अध्ययन Study — at your own pace, on your own device

A learning companion for Sanskrit stotras. Read a stotra as a continuous recitation or study it verse-by-verse with notes, search across scripts using plain English typing, and adjust font size or meaning visibility on the fly. Everything runs on your phone — no accounts, no servers, no tracking.

The APK is a signed release build published from the project's GitHub Actions workflow. On first install Android may ask you to allow installs from your browser — the app itself contains no ads, trackers, or network calls beyond fetching optional content.

What's inside

📖

Two readers, one text

Read a stotra as a continuous list for recitation, or switch to a paginated study view — one verse per page, with adjacent notes grouped so an eight-verse ashtakam paginates as eight pages.

🔤

Romanized search

Search runs on a diacritic-folded romanized form, so bhavani matches Bhavānī. Every listing has a romanized English title, so you can find a stotra without knowing Devanagari.

🎚️

Live reader controls

A persistent inline toolbar on both readers steps font size and toggles meaning on or off. Changes apply instantly across every page — Settings just holds the defaults.

✈️

Offline first

Content is bundled with the app and rendered from local JSON. The network is optional — the reader keeps working with the phone in airplane mode.

🔒

Nothing to breach

No accounts, no login, no analytics. There is no server holding your progress — each install is a self-contained copy on your device.

🧩

Editable source of truth

Runtime content is generated from romanized SLP1 source files, so each stotra has a single canonical form that scripts and future transliterations can be regenerated from.

Built with

Ionic React + Capacitor, TypeScript, Vite, and Redux for state. The Android app is packaged from the web build via Capacitor and signed in GitHub Actions before publishing to the release page above.
