Why communities trust it

🔒

Zero attack surface

No servers, no accounts, no central database — there's nothing to breach. Every install only ever holds what you import, on that device.

👁️

Screenshot-blocked

The Android app blocks screenshots and screen recording, and hides its content from the recent-apps preview.

🧩

Multiple communities, isolated

One install can hold several communities, each scoped by CommunityCode — never mixed, never overwritten by accident.

📅

Minimal data by default

Only a birth year is collected, not a full date of birth — less sensitive data at rest, less to lose.

The short version

1

Build your CSV

Use the Google Sheet CSV builder — it fills in the identity columns for you.

2

Import it

Export the CSV and import it in the app (Menu ▸ Import Data).

3

Keep the same code

Same CommunityCode every time — re-importing upgrades your data instead of duplicating it.

4

Families self-serve

Each family gets a permanent FamilyId, shown to them in-app, to quote when requesting an update.

🔒 Zero attack surface, by design. There's no server to breach and no account database to leak — every install stores only its own imported CSV(s), only on that device.
